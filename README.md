# ST-DiffEye Project Page

Project page for **ST-DiffEye: Diffusion-based Continuous Gaze Generation via Joint Scanpath-Trajectory Modeling**.

Served via GitHub Pages from `index.html` at the repository root.

## Structure

- `index.html` — the project page
- `static/css`, `static/js` — Bulma-based template assets (from the [Academic Project Page Template](https://github.com/eliahuhorwitz/Academic-project-page-template))
- `static/images` — figures cropped from the paper
- `static/papers/st-diffeye.pdf` — the paper PDF
